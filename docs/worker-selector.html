Worker Image Selector

Select the Camel components you need, and we'll calculate the lightest precompiled worker image for Ephemeral mode.

Select Components

The operator automatically selects the smallest image that contains all your required components. If your components span multiple domains, it falls back to the camel-worker-full image.
