================================================================================
  Ephemeral SaaS examples — v0.8.0 catalog integrations
================================================================================

These flows run in EPHEMERAL mode (no Git). Each example uses timer→log or
platform-http patterns from docs/flow-catalog.json buckets:

  saas-messaging, crm-support, productivity, devops, commerce-latam,
  ai-mcp (flagship), identity-secrets

Worker images: quay.io/maximilianopizarro/camel-worker-*:v0.8.0

Prerequisites (per integration)
--------------------------------
  Create the Secret named in each YAML before apply. Catalog flows include
  authType, requiredSecrets, suggestedProperties, and credentialHints.

  oc apply -f k8s/examples/23-ephemeral-slack.yaml
  oc get integrationflow -n openshift-integration -w
  oc logs deploy/iflow-ephemeral-slack-notify-worker -n openshift-integration -f

authType cheat sheet
--------------------
  oauth2_refresh      Gmail, Office365, Salesforce, Google Workspace, LinkedIn
  static_token_webhook Slack webhook, Telegram, Discord, Teams, WhatsApp
  api_key             Twilio, HubSpot, Stripe, Mercado Pago, OpenAI, Vault
  basic_auth          Zendesk, Freshdesk, WooCommerce, Confluence

Worker image selection
----------------------
  camel-worker-messaging  Slack (webhook)
  camel-worker-full       Telegram, Twilio, Gmail, Salesforce, Google Sheets
  camel-worker-http       HubSpot, GitLab, Mercado Pago, Shopify webhooks/REST
  camel-worker-ai         OpenAI / flagship messaging-llm-mcp-auto-reply

See also: docs/ephemeral-ai-examples.txt for LLM-only flows.
