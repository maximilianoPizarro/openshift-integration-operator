Quick Start

Install the operator with Helm in under a minute.

# Add the Helm repository
helm repo add integration-platform \
  https://maximilianopizarro.github.io/openshift-integration-operator/

helm repo update

# Install the operator
helm install integration-operator \
  integration-platform/openshift-integration-operator \
  --namespace openshift-integration \
  --create-namespace

# Verify the deployment
oc get pods -n openshift-integration
oc get crd integrationflows.platform.io

Precompiled Worker Images

All images are published to Quay.io and auto-selected based on detected Camel components. The operator parses your kaotoDesign YAML to extract all uri: component schemes (e.g. kafka, platform-http, sql), then selects the smallest tier image whose extension set covers all detected components. If components span multiple domains, it falls back to camel-worker-full. Override with spec.ephemeral.workerImage to pin a specific image.

# Default (all domains — 80+ extensions)
quay.io/maximilianopizarro/camel-worker-full:v0.4.1

# Domain-specific (smaller, faster startup)
quay.io/maximilianopizarro/camel-worker-core:v0.4.1        # timer, log, direct, seda, bean
quay.io/maximilianopizarro/camel-worker-messaging:v0.4.1   # kafka, amqp, jms, mqtt, nats
quay.io/maximilianopizarro/camel-worker-http:v0.4.1        # platform-http, rest, graphql, grpc
quay.io/maximilianopizarro/camel-worker-data:v0.4.1        # sql, jdbc, mongodb, file, ftp
quay.io/maximilianopizarro/camel-worker-cloud:v0.4.1       # aws2-s3/sqs/sns, azure, google
quay.io/maximilianopizarro/camel-worker-ai:v0.4.1          # langchain4j-chat, djl

Override auto-selection

# Force a specific worker image instead of auto-detection
spec:
  deploymentMode: EPHEMERAL
  ephemeral:
    ttlSeconds: 3600
    workerImage: quay.io/maximilianopizarro/camel-worker-messaging:v0.4.1

Architecture

A Kubernetes-native platform that connects visual design, GitOps, and runtime observability.

The operator reconciles IntegrationFlow custom resources through scaffolding, Git push, Tekton builds, and ArgoCD deployment. The console plugin embeds Kaoto and streams live telemetry over SSE to color canvas nodes in real time.
